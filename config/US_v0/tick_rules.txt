# Instructions that run only on the game's whole ticks at 60 fps (docs/recompiler-design.md D21).
# At 60 fps the game's frame runs every vsync; a frame between two of its 30 Hz ticks (a half tick)
# draws, but the game's own logic must not advance. tools/recomp/generate.py wraps each listed
# instruction in `if (RT_WHOLE_TICK())`, which is always true at 30 fps, so nothing changes there.
# A rule names the instruction it expects: a call (`bl TARGET`, `bctrl`) or a plain store (its
# mnemonic); `whole:r3=N` also sets r3 when a skipped call's caller tests the result. Evidence: the
# GameCube decomp's functions (zeldaret/tww) matched call by call, and the 60 fps state probe and
# store census (src/overrides/sixty.cpp, tools/sixty).
#
