# At 60 fps the game's frame runs every vsync; a frame between two of its 30 Hz ticks (a half tick)
# draws, but the game's own logic must not advance. tools/recomp/generate.py wraps each listed
# instruction in `if (RT_WHOLE_TICK())`, which is always true at 30 fps, so nothing changes there.
