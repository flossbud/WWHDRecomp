# ---- fireflies (FF, process 187, d_a_ff.cpp: "Object - Firefly (not collectable)"; Forest Haven has 77):
# the five timers counted down at the top of the execute (f_02133070, a loop), mLiveTimer + 1 a tick (the
# glow's spin and the scale's wave), and the move pos += speed + mVelImpulse, a vector add.
02133110    whole       sthx            ff execute: mTimers[i] (+0x424) - 1, read later from memory
02133178    whole       sth             ff fire_fly_move: mLiveTimer (+0x42E) + 1
02133914    vec@r4      bl 028e8d88     ff fire_fly_move: pos += speed + mVelImpulse (PSVECAdd of their sum)
#
# ---- forest fireflies, the collectable ones (NH, process 313, d_a_nh.cpp): speed.y moved toward
# maxFallSpeed by gravity a tick in the execute, either way (then fopAcM_posMove).
021E11E4    *h@f11      fsubs           nh execute: speed.y -= gravity (above maxFallSpeed)
021E1208    *h@f12      fadds           nh execute: speed.y += gravity (below it)
#
# ---- lily pads (LEAF_LIFT, process 120, d_a_leaflift.cpp): the lifetime count (the tilt's wobble when
# Link rides it), m43F's countdown (0 then sets m43E at once: keep), the slerp toward the target tilt
# (0.25 a tick), and WWHD's ripple count (MoveDownLift: + 1 a tick; 200 ends the ripples).
021B3D40    whole       sth             leaflift _execute: mActorLifetimeFrameCount (+0x560) + 1
021B3D48    keep:r9     addi            leaflift _execute: m43F (+0x55B) - 1, then 0 sets m43E
021B3EB8    k@f1        bl 028e9bc0     leaflift _execute: mDoMtx_quatSlerp(cur, target, 0.25)
021B40C4    whole       stw             leaflift MoveDownLift (WWHD): mEmitterTimer (+0x5B8) + 1
#
# ---- baba buds (JBO, process 213, d_a_jbo.cpp): mFramesUntilJump counted down before jbo_move reads it
# (70 ticks from Link's entering to the launch), the wobble's angle += mAnimationSpeed a tick (in
# jbo_draw_SUB, from the execute), and the launch itself (player->onForceVomitJump: a flag on Link, set
# while the count is 1, which both steps of the tick would see).
0218474C    whole       sth             jbo execute: mFramesUntilJump (+0x3DA) - 1
02184564    split@r0    add             jbo jbo_draw_SUB: mAnimRotation (+0x3DC) += mAnimationSpeed
02184884    whole       stw             jbo jbo_move: onForceVomitJump, Link's flag (+0x3BC |= 0x10)
